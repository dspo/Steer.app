## 定位记录（一次真实的接错 → 修对）

首跑 409/42/116，ours=2（`DECSET_Allow80To132`、`DECSET_DECCOLM`）：内核在 DEC mode 40 开启时对
`?3 h` **自行**缩放网格（`Terminal.deccolm` → `self.resize`，不走 resize 回调），而尺寸回调当时
答的是布局快照——esctest 把 `?3 h` 与 `CSI 18 t` 写进同一 PTY 块时，回调在 write 内部触发，
快照还停在旧值。修法：尺寸回调经 `TerminalRef` 直接读内核实时网格（C shim 的 `get` 不加锁、
同线程读安全），合块回归用例 `size_query_answers_a_self_resize_in_the_same_chunk` 锁住行为。
